# 法律计算器大全

面向律师、企业法务与合规人员的在线计算工具集，**45 个计算器 / 7 大类**，每个计算器均输出分步明细与法律依据条文，并支持把多个测算项组装成报告，导出 Markdown / Word / Excel / HTML / PDF。

本版重点补齐了诉讼中最易漏算的四项实际支出：**公告费、公证费、鉴定费、评估费**（并已在上一版覆盖 **保全保险费**）。这五项都不属于案件受理费，法院不代收代付，须由当事人直接支付给第三方机构，往往是诉讼中最大的现金流出。

## 报告中心（汇报用）

1. 在任一计算器页填写**项目档案**：项目名称（如「张某经济补偿金（协商解除）」）、时间、项目人、代理人，以及**当事人清单**（可添加多方，逐条标记我方 / 对方 / 第三方并填写诉讼或合同地位），点「加入报告」；也可在报告中心点「+ 添加项目」勾选多个计算项
2. 项目名称会成为报告中该章节的标题，并出现在开头的**测算概览表**里（概览表含 序号 / 项目名称 / 我方 / 对方 / 时间 / 项目人 / 代理人 / 结果项 / 结果数值），汇报沟通时可直接按名称定位
3. 可自定义报告标题、项目/客户、编制人、总体说明，以及每项的名称与结论备注；每个项目单独输出一张**项目档案表**（时间、我方、对方、第三方、项目人、代理人）
4. 可调整项目顺序，并勾选是否导出输入参数、计算明细、法律依据、实务提示
5. 右侧实时预览，一键导出：

| 动作 | 适用场景 |
|---|---|
| 复制 Markdown | 粘贴到飞书文档、钉钉文档、Notion |
| 复制精简文本 | 直接发到微信 / 钉钉会话 |
| 分享到微信/钉钉 | 移动端唤起系统分享面板 |
| 下载 .md / .txt | 纯文本归档 |
| 下载 Word | 本机 Word / WPS 打开，可另存 docx 或上传飞书、钉钉文档 |
| 下载 Excel | 概览 + 每个计算项一张明细工作表 |
| 下载 HTML | 独立网页，可直接分享、浏览器打开 |
| PDF（打印） | 调起打印对话框，选择「另存为 PDF」 |

命令行同样可生成报告（适合批量或自动化）：

```bash
npx tsx skill/scripts/cli.ts --report examples/report.sample.json --format md --out 报告.md
# format 可选：md | html | doc | xlsx | text
```

完整示例见 `examples/report.sample.json`。`items[]` 支持的项目档案字段：

| 字段 | 说明 |
| --- | --- |
| `title` | 项目名称，作为报告中该章节标题 |
| `date` | 时间（事发日 / 签约日 / 测算基准日） |
| `owner` | 项目人（我方内部负责人） |
| `agent` | 代理人（承办律师 / 代理人） |
| `parties[]` | 当事人列表，`side` 取 `us`（我方）/ `opposite`（对方）/ `third`（第三方），`role` 填诉讼或合同地位 |
| `note` | 结论备注 |

## 数据来源与免责

- 诉讼费用依据《诉讼费用交纳办法》（国务院令第481号）；公告、公证、鉴定、评估等实际支出费用适用其第十二条「谁主张、谁负担，由当事人直接支付给有关机构」
- 公证费依据《公证法》第 37 条、第 46 条及各省公证服务收费标准
- 司法鉴定依据《民事诉讼法》第 79 条、《全国人大常委会关于司法鉴定管理问题的决定》及各省级司法鉴定收费标准
- 评估费依据行业通行的累进计费标准（资产评估 / 房地产估价 / 土地估价），现已多为市场调节价
- 利息与违约金依据《民法典》及《民间借贷规定》《迟延履行利息解释》《民法典合同编通则司法解释》
- 劳动争议依据《劳动法》《劳动合同法》《工伤保险条例》《职工带薪年休假条例》
- 税务依据《印花税法》《个人所得税法》及配套规定
- 差旅依据《中央和国家机关差旅费管理办法》（企业标准可自行制定）

**需要人工核对的参数**：各地按件收取的受理费幅度、工伤一次性医疗/就业补助金月数、社保费率与缴费基数上下限、最低工资标准、当地上年度职工月平均工资、一年期 LPR 当期公布值、全国城镇居民人均可支配收入年度数据、**公告刊登单价、公证收费标准、司法鉴定单价与费率、评估机构报价及折扣**（四项均为市场调节价，务必以机构书面报价为准）。

计算结果仅供参考，不构成法律意见。条文序号随法律修正而变动（尤其《民事诉讼法》），引用前请对照现行版本核对。内置的 2026 年节假日为按常规规则推定，国务院办公厅正式通知发布后请以官方为准。
