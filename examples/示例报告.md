### 结论备注

月工资未超当地社平工资三倍，不适用封顶；建议以本金额为谈判起点。

### 法律依据

- **《劳动合同法》 第四十七条**：经济补偿按劳动者在本单位工作的年限，每满一年支付一个月工资的标准向劳动者支付。六个月以上不满一年的，按一年计算；不满六个月的，向劳动者支付半个月工资的经济补偿。劳动者月工资高于用人单位所在直辖市、设区的市级人民政府公布的本地区上年度职工月平均工资三倍的，向其支付经济补偿的标准按职工月平均工资三倍的数额支付，向其支付经济补偿的年限最高不超过十二年。
- **《劳动合同法实施条例》 第二十七条**：经济补偿的月工资按照劳动者应得工资计算，包括计时工资或者计件工资以及奖金、津贴和补贴等货币性收入。劳动者工作不满12个月的，按照实际工作的月数计算平均工资。

### 实务提示

- 月工资基数按"应得工资"计算，含奖金、津贴、补贴和加班工资，不是基本工资，也不是实发工资。
- 2008 年 1 月 1 日前后经济补偿规则不同，涉老案工龄需分段适用当时规定，本工具按现行统一规则计算。
- 劳动者非因本人原因被安排到新单位的，原单位工作年限合并计算。

> 工作日 / 休息日 / 法定节假日三类加班工资计算

### 计算结果

**加班费总额：127,994.40 元**

> 壹拾贰万柒仟玖佰玖拾肆元叁角

| 项目 | 数值 |
| --- | --- |

| 工作日加班费 | 5,517.00 元 |
| 休息日加班费 | 2,942.40 元 |
| 法定节假日加班费 | 2,206.80 元 |

### 输入参数

| 参数 | 取值 |
| --- | --- |
| 月工资（加班费计算基数） | 16000 元 |
| 工作日延时加班小时数 | 40 小时 |
| 休息日加班小时数 | 16 小时 |
| 休息日是否已安排补休 | 否 |
| 法定节假日加班小时数 | 8 小时 |

### 计算明细

| 步骤 | 计算过程 |
| --- | --- |
| 日工资 | 16,000.00 ÷ 21.75 = 735.63 元　*月计薪天数 21.75 天* |
| 小时工资 | 735.63 ÷ 8 = 91.95 元 |
| 工作日延时加班（150%） | 91.95 × 40 小时 × 150% = 5,517.00 元　*《劳动法》第44条第（一）项* |
| 休息日加班（200%） | 91.95 × 16 小时 × 200% = 2,942.40 元　*《劳动法》第44条第（二）项* |
| 法定节假日加班（300%） | 91.95 × 8 小时 × 300% = 2,206.80 元　*《劳动法》第44条第（三）项，不可用补休替代* |
| 单月加班费合计 | 10,666.20 元 |
| 追索 12 个月 | 10,666.20 × 12 = 127,994.40 元 |

### 结论备注

考勤记录由公司掌握，举证不利风险高，建议核实加班审批流程是否完整。

### 法律依据

- **《劳动法》 第四十四条**：有下列情形之一的，用人单位应当按照下列标准支付高于劳动者正常工作时间工资的工资报酬：（一）安排劳动者延长工作时间的，支付不低于工资的百分之一百五十的工资报酬；（二）休息日安排劳动者工作又不能安排补休的，支付不低于工资的百分之二百的工资报酬；（三）法定休假日安排劳动者工作的，支付不低于工资的百分之三百的工资报酬。
- **《关于职工全年月平均工作时间和工资折算问题的通知》**：月计薪天数＝（365天－104天）÷12月＝21.75天。

### 实务提示

- 法定节假日加班费不可用补休替代，必须支付 300%；休息日加班则可以优先安排补休。
- 加班费计算基数有约定的从约定，但不得低于当地最低工资标准；无约定的通常按正常工作时间工资确定。
- 加班事实的举证责任原则上由劳动者承担，但用人单位保有的考勤记录、工资表应由单位提供，拒不提供可采信劳动者主张。

## 4. A 客户逾期付款违约金

> 按日万分之X 或固定金额计算逾期违约金，并同步校验司法保护上限

### 输入参数

| 参数 | 取值 |
| --- | --- |
| 违约所涉价款 / 本金 | 3000000 元 |
| 违约金约定方式 | 按日计算（日万分之X） |
| 日违约金率 | 5 ‱（万分之） |
| 违约行为发生日 | 2025-01-01 |
| 计算截止日 | 2026-09-30 |
| 合同约定的违约金上限 | 30 % |
| 实际损失（用于调减审查） | 400000 元 |

### 计算明细

| 步骤 | 计算过程 |
| --- | --- |
| 违约持续期间 | 2025-01-01 至 2026-09-30，共 637 天 |
| 按日计算 | 3,000,000.00 × 5‱ × 637 天 = 955,500.00 元 |
| 折合年化 | 18.25% |
| 触发合同违约金上限 | 3,000,000.00 × 30% = 900,000.00 元　*合同约定上限优先于按日累计结果* |
| 司法调减审查（损失 × 130%） | 400,000.00 × 130% = 520,000.00 元 |
| 审查结论 | ⚠ 超过损失 30%，一般可认定为"过分高于造成的损失"　*《民法典合同编通则司法解释》第65条* |

### 结论备注

合同约定日万分之五，逾期已逾一年，存在被请求调减的风险，建议按损失 130% 预留谈判空间。

### 法律依据

- **《民法典》 第五百八十五条**：当事人可以约定一方违约时应当根据违约情况向对方支付一定数额的违约金，也可以约定因违约产生的损失赔偿额的计算方法。约定的违约金低于造成的损失的，人民法院或者仲裁机构可以根据当事人的请求予以增加；约定的违约金过分高于造成的损失的，人民法院或者仲裁机构可以根据当事人的请求予以适当减少。
- **《民法典合同编通则司法解释》 第六十五条**：约定的违约金超过造成损失的百分之三十的，人民法院一般可以认定为民法典第五百八十五条第二款规定的"过分高于造成的损失"。

### 实务提示

- 违约金调减以"当事人请求"为前提，法院一般不主动调整，被告需明确提出抗辩。
- 主张违约金过高的一方应承担初步举证责任，之后由主张违约金的一方举证实际损失。
- 日万分之五折合年化 18.25%，在长周期逾期中极易被调减，建议同步约定 30% 总额上限以提高稳定性。

### 计算明细

| 步骤 | 计算过程 |
| --- | --- |
| 1000 元以下或不涉及财产数额 | 1,000.00 定额 = 30.00 元 |
| 1000 元—10 万元部分 | 99,000.00 × 1% = 990.00 元 |
| 10 万元以上部分 | 2,900,000.00 × 0.50% = 14,500.00 元 |
| 分段累计 | 15,520.00 元 |
| 适用封顶 | 超出 5,000.00 元，按 5,000.00 元交纳　*《诉讼费用交纳办法》第十四条第（三）项* |
| 封顶减负 | 15,520.00 − 5,000.00 = 少交 10,520.00 元 |

### 结论备注

300 万标的的保全申请费已触及 5,000 元封顶，此后增加标的额不再多交。

### 法律依据

- **《诉讼费用交纳办法》 第十四条第（三）项**：申请保全措施的，根据实际保全的财产数额按照下列标准交纳：财产数额不超过1000元或者不涉及财产数额的，每件交纳30元；超过1000元至10万元的部分，按照1%交纳；超过10万元的部分，按照0.5%交纳。但是，当事人申请保全措施交纳的费用最多不超过5000元。
- **《民事诉讼法》 第一百零三条**：人民法院对于可能因当事人一方的行为或者其他原因，使判决难以执行或者造成当事人其他损害的案件，根据对方当事人的申请，可以裁定对其财产进行保全、责令其作出一定行为或者禁止其作出一定行为；当事人没有提出申请的，人民法院在必要时也可以裁定采取保全措施。人民法院采取保全措施，可以责令申请人提供担保，申请人不提供担保的，裁定驳回申请。

### 实务提示

- 保全申请费 5,000 元封顶：标的额超过约 89 万元后即封顶，此后增加标的额不再多交申请费。
- 申请费由申请人在提出申请时预交，最终由败诉方负担；部分撤诉或保全错误的情形按实际情况分担。
- 超标的保全可能被认定为保全错误，需承担赔偿责任，请求保全的数额应与债权额相当。
- 保全的实际成本大头往往是担保费而非申请费——担保费请用「财产保全担保费」单独测算。
