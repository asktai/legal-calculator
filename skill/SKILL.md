面向法务、律师、合规与企业法律顾问的一站式测算工具集，共 **45 个计算器 / 7 大类**。核心计算逻辑为**纯函数**（`src/core/`），与网页端、命令行、技能包共用同一份实现，保证同一输入在任何入口得到完全一致的结论。

本版把**法定口径回归审计升级为全业务覆盖**：70 个按法条手算的期望值逐一比对全部 45 个计算器（此前仅覆盖 15 个），并为 LPR 四倍上限核减、砍头息还原本金、年复利、违约金司法酌定、综合费率超限、个税分档、劳务报酬预扣与汇算、违约金价税分离、破产受理费 30 万封顶、工伤社平 300% 封顶、竞业限制期限截断、二倍工资 11 个月上限、春节顺延与调休上班日不顺延等关键分支单独加测；`audit.ts` 末尾新增**覆盖断言**——任一计算器无用例即 FAIL，计算口径回退在发版前即被拦截。此前版本已升级报告导出：**导出文件名按「当事方主体简称_事项_费用类型_生成时间」四段式自动生成**（如 `华润万佳_租赁合同纠纷_财产案件受理费_20260925-0134.xlsx`，网页端与 CLI 共用同一命名函数，当事人档案新增「简称」字段、留空自动用全称）；**七种格式（Markdown / Word / Excel / HTML / PDF / 纯文本 / PNG 长图）自选、多选、一键批量导出**，每种格式导出即做结构校验并给出核对结论；CLI 端 `--format` 支持逗号分隔多选、同分钟重复导出自动追加 -2 / -3 避让重名，PDF 由 Chromium 无头打印直接生成 A4 文件。更早版本补齐了诉讼中极易被漏算的**保全保险费、公告费、公证费、鉴定费、评估费**五项实际支出——它们不属于案件受理费，法院不代收代付，往往是诉讼中最大的现金流出。

**版本怎么核对与升级**（全程不联网，更新源由使用者自己给）：

```bash
cd skill
npx tsx scripts/version.ts                       # 版本身份证：版本 / 作者 / 许可 / 规模
npx tsx scripts/version.ts --check <目录或 zip>    # 与更新源比对（也可 --watch 登记后省略源）
npx tsx scripts/version.ts --changelog <源>       # 摘出「当前版本 → 源版本」之间的沿革条目
npx tsx scripts/version.ts --upgrade <源> --target <安装目录>            # 预演（不动任何文件）
npx tsx scripts/version.ts --upgrade <源> --target <安装目录> --apply    # 真升级（先整目录备份）
npx tsx scripts/version.ts --notice               # 静默检查：无新版完全不输出，有新版才提示
```

> **升级永远是使用者说了算。** `--notice` 只提示不改动；`--upgrade` 不带 `--apply` 就是预演。发现新版就自动替使用者升级是明确排除的行为——版本换季可能改变计算口径与产出形态，必须由人判断何时切。升级时 `examples/` 永不覆盖，目标独有的文件一律保留。

**装好后先自检一遍**（技能包自带 `lib/`，**不依赖开发侧的 `src/`**，装到任何目录都能跑）：

```bash
cd <技能目录>
npx tsx scripts/check.ts        # 包内自检：结构完整 / 版本三处一致 / 45 个计算器可载入并试算
npx tsx scripts/smoke.ts        # 全部计算器冒烟
npx tsx scripts/audit.ts        # 70 条法定口径用例回归
npx tsx scripts/cli.ts --list   # 列出 45 个计算器
```

> 版本号在包内出现三处：`SKILL.md` frontmatter、`CARD.md` 注册块、`lib/version.mjs`。
> 前两处是文档，`lib/version.mjs` 是出包时依 `SKILL.md` 生成的派生物；`check.ts` 会比对三者，
> 不一致即报「bundle 是旧版，须重跑 build-skill-bundles.mjs」——防止"文档升了版、包内脚本还是旧口径"。

## 快速开始

> 下面的命令都在**技能目录**（含 `SKILL.md` 的那一层）内执行；
> 开发仓库里该目录是 `skill/`，装成技能后就是 `legal-calculator/`。

```bash
cd "$(dirname "$0")"    # 或直接 cd 到技能目录

# 列出全部计算器

# 按关键词搜索
npx tsx skill/scripts/cli.ts --search 违约金

# 执行单个计算（参数用 --key=value）
npx tsx skill/scripts/cli.ts civil-fee --amount=1000000

# 生成汇总报告
npx tsx skill/scripts/cli.ts --report examples/report.sample.json --format md --out 汇报.md
```

Web 应用：

```bash
pnpm install
pnpm dev      # http://localhost:5173
```

## 计算器清单（45 个 / 7 大类）

### 1. 诉讼费用（12）

| id | 名称 | 说明 |
| --- | --- | --- |
| `civil-fee` | 财产案件受理费 | 按诉讼请求金额超额累进计算一、二审案件受理费 |
| `non-property-fee` | 非财产案件受理费 | 离婚、人格权、劳动争议等非财产案件的受理费标准 |
| `preservation-fee` | **财产保全费** | 向法院申请查封、扣押、冻结的保全申请费，按保全财产数额累进、5,000 元封顶（只算法院收费） |
| `preservation-guarantee-fee` | **财产保全担保费** | 法院要求担保时购买保全责任保险 / 银行保函的费用，或现金担保的资金占用成本（非法院收费） |
| `execution-fee` | 执行申请费 | 按执行金额计算申请强制执行应交费用（执行后由被执行人负担） |
| `application-fee` | 支付令及其他申请费 | 支付令、公示催告、撤销仲裁裁决等申请的收费标准 |
| `lawyer-fee` | 律师服务费 | 计件、按标的额比例、计时与风险代理四种计费方式测算 |
| `announcement-fee` | **公告费** | 送达、开庭、执行、破产、公示催告等公告的刊登费（按次 × 单价） |
| `notarization-fee` | **公证费** | 强制执行公证（0.3%）、继承赠与（累进）、合同公证（累进）、保全证据与文本相符（按件）、提存 |
| `expertise-fee` | **司法鉴定费** | 笔迹、医疗损害、工程造价、司法会计等，支持按件或按标的额计费，含鉴定人出庭费 |
| `valuation-fee` | **评估费** | 资产评估 / 房地产估价 / 土地估价按评估值累进计费，支持市场折扣与最低收费 |
| `litigation-total` | 诉讼成本总览 | 一次性汇总受理费、保全费与保全担保费、律师费与公告费、公证费、鉴定费、评估费等全部投入 |

### 2. 利息与违约金（7）

`lpr-interest` 民间借贷利息与上限 · `delay-interest` 迟延履行加倍利息 · `general-interest` 一般债务利息 · `contract-penalty` 违约金计算器 · `penalty-adjust` 违约金司法调整 · `loan-compliance` 借款利率合规体检 · `occupation-loss` 资金占用损失

### 3. 劳动争议（8）

`severance` 经济补偿金（N） · `illegal-termination` 违法解除赔偿金（2N） · `overtime-pay` 加班费 · `annual-leave-pay` 未休年休假工资 · `double-wage` 未签劳动合同二倍工资 · `work-injury` 工伤伤残赔偿 · `work-death` 工亡赔偿 · `non-compete` 竞业限制补偿金

### 4. 时效与期限（6）

`limitation-period` 诉讼时效届满日 · `period-calc` 法定期间推算 · `appeal-deadline` 上诉期/答辩期 · `execution-apply` 申请执行期间 · `retrial-deadline` 再审申请期限 · `arbitration-limitation` 劳动仲裁时效

### 5. 税务（5）

`stamp-duty` 合同印花税 · `personal-income-tax` 工资薪金个人所得税 · `labor-remuneration-tax` 劳务报酬所得税 · `penalty-tax` 违约金/赔偿金涉税 · `social-insurance` 社保公积金与用工成本

### 6. 差旅费用（3）

`travel-allowance` 差旅补贴标准 · `travel-reimburse` 差旅报销核算 · `travel-budget` 年度差旅预算

### 7. 法务成本（4）

`case-cost` 单案件法务成本 · `counsel-compare` 律师计费方案比选 · `dispute-decision` 争议解决方式对比 · `legal-dept-roi` 法务部门投入产出

## 典型用法

### 单项目测算

```bash
# 1000 万标的：法院收取的保全申请费（5,000 元封顶）
npx tsx skill/scripts/cli.ts preservation-fee --amount=10000000
#  → 【保全申请费（法院）】 5,000.00 元（伍仟元整）

# 同上标的：保险公司保函费（非法院收费，单独测算）
npx tsx skill/scripts/cli.ts preservation-guarantee-fee \
  --amount=10000000 --guarantee=insurance --guaranteeRate=0.8 --years=1 --minPremium=500
#  → 【保全保险费】 8,000.00 元（捌仟元整）

# 100 万标的的一审受理费
npx tsx skill/scripts/cli.ts civil-fee --amount=1000000
#  → 13,800.00 元

# 违约金：1000 万本金，日万分之五，逾期 545 天
npx tsx skill/scripts/cli.ts contract-penalty \
  --principal=10000000 --dailyRate=5 --startDate=2025-01-01 --endDate=2026-06-30

# 破产公告连续刊登 3 次（单价留空自动采用参考价 1500 元/次 → 4500 元）
npx tsx skill/scripts/cli.ts announcement-fee --annoType=bankruptcy --times=3

# 1 亿元债务的强制执行公证费（0.3% → 30 万元）
npx tsx skill/scripts/cli.ts notarization-fee --notaryType=enforcement --amount=100000000

# 3000 万标的的工程造价鉴定，按 2% 计费 → 60 万元
npx tsx skill/scripts/cli.ts expertise-fee --expType=engineering --method=byamount --amount=30000000 --rate=2

# 5000 万元房地产估价，按标准价 6 折
npx tsx skill/scripts/cli.ts valuation-fee --valType=realestate --value=50000000 --discount=60
```

> 公告费与鉴定费的「单价」字段留空（填 0）时，会自动采用所选类型的行业参考价；有机构实际报价时直接填写即可覆盖。

### 汇总报告（支持项目档案）

报告 JSON 结构：

```json
{
  "title": "XX 项目法务测算报告",
  "subject": "XX 有限公司",
```

## 关键计算规则

- **案件受理费**：财产案件按诉讼请求金额超额累进（《诉讼费用交纳办法》第 13 条），简易程序、调解结案或撤诉减半交纳。
- **保全申请费**：按保全财产数额超额累进，**最高不超过 5000 元**（《诉讼费用交纳办法》第 14 条第三项）。
- **保全保险费**：保险公司保函 / 银行保函按保函金额 × 费率（市场区间 0.5‰—1.5‰/年）× 保全期限计收，通常设最低保费（多为 500—1000 元）。实务中保全的实际支出大头往往是保险费而非申请费，报价前须先行询价。
- **公告费**：送达公告自发出之日起经过 **30 日**即视为送达（《民事诉讼法》第 95 条）；宣告失踪公告期 3 个月、宣告死亡 1 年；公示催告期间不少于 60 日；涉外公告送达满 3 个月视为送达。费用由当事人直接支付给人民法院报社或法院公告网，**法院不代收代付**。
- **公证费**：赋予债权文书强制执行效力公证按债务总额 **0.3%** 计收（行业通行标准），可据此直接申请强制执行，省去一审受理费与保全费；继承、赠与、接受遗赠公证按受益额累进（20 万以下 1.2%，20—50 万 1%，50—500 万 0.8%，500—1000 万 0.5%，1000 万以上 0.1%）；收费标准由省级价格主管部门与司法行政部门制定，多已放开为市场调节价（依据《公证法》第 46 条）。
- **鉴定费**：由申请方在举证期限届满前提出并垫付，最终由败诉方负担；鉴定人出庭的交通费、住宿费、生活费与误工补贴属《诉讼费用交纳办法》第 6 条规定的诉讼费用。工程造价鉴定常见 1%—3%、司法会计鉴定常见 0.5%—2%，其余多为按件计费。
- **评估费**：资产评估、房地产估价、土地估价均按评估值**差额定率累进**计费（行业参考标准，现已多为市场调节价，实务常按标准价 5—8 折成交）。司法拍卖中的评估费由申请执行人垫付，最终从拍卖款中优先扣除。
- **执行申请费**：执行申请费不由申请方预交，执行后由被执行人负担（《诉讼费用交纳办法》第 20 条）。
- **迟延履行加倍利息**：加倍部分债务利息 = 债务人尚未清偿的生效法律文书确定的除一般债务利息之外的金钱债务 × **日万分之一点七五** × 迟延履行期间（《民事诉讼法》第 264 条）。
- **民间借贷利率上限**：约定利率不得超过合同成立时**一年期 LPR 的四倍**（2020 年 8 月 20 日《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》）。
- **砍头息**：预先在本金中扣除利息的，按实际借款数额返还借款并计算利息（《民法典》第 670 条）。
- **违约金调整**：约定违约金超过造成损失的 **30%** 的，一般可认定为「过分高于造成的损失」（《民法典合同编通则司法解释》第 65 条）。
- **经济补偿金 N**：每满一年支付一个月工资；月工资高于本地区上年度职工月平均工资三倍的，按三倍数额支付且年限最高不超过 12 年（《劳动合同法》第 47 条）。
- **月计薪天数**：**21.75 天/月**（《关于职工全年月平均工作时间和工资折算问题的通知》），加班费与未休年休假工资均以此为基数。
- **未签书面劳动合同二倍工资**：用工之日起满一个月的次日至满一年的前一日，最长 11 个月（《劳动合同法》第 82 条）。
- **一次性工亡补助金**：上一年度全国城镇居民人均可支配收入的 **20 倍**（《工伤保险条例》第 39 条）。
- **诉讼时效**：普通时效 3 年，自权利人知道或应当知道权利受损及义务人之日起算；自权利受损之日起超过 20 年的法院不予保护（《民法典》第 188 条）。
- **法定期间**：期间届满的最后一日为节假日的，以节假日后的第一日为期间届满日；期间不包括在途时间，诉讼文书在期满前交邮的不算过期（《民事诉讼法》第 85、86 条）。
- **劳动争议仲裁时效**：1 年；劳动关系存续期间因拖欠劳动报酬发生争议的不受 1 年限制，但劳动关系终止的应自终止之日起 1 年内提出（《劳动争议调解仲裁法》第 27 条）。

## 版本兼容性说明

- 计算器 `id` 一经发布即保持稳定，报告 JSON 中的 `calcId` 可跨 PATCH / MINOR 版本复用；MAJOR 版本升级前会给出迁移提示。
- V1.1.0 起 `litigation-total` 的 `appraisal`（旧「鉴定/公证等其他费用」）拆分为 `announcementFee` / `notarizationFee` / `appraisalFee` / `valuationFee` 四个字段，旧 JSON 中的 `appraisal` 仍会被读取并计入鉴定费，无需迁移。
- 公告费、公证费、鉴定费、评估费的参考价均为行业通行标准，非法定固定价；涉及具体案件时应以受理法院、公证处、鉴定机构、评估机构的书面报价为准。
- 新增字段一律提供默认值，旧版报告 JSON 缺字段时自动按默认值补齐，不会报错。
- 节假日表内置 2024—2027 年数据，超出该范围的期间推算不会自动顺延节假日，需人工复核。
- LPR、职工月平均工资、城镇居民人均可支配收入等随政策变动的参数以表单默认值为准，使用前请核对是否适用最新公布值。
