## 卡片简介（展示文案）

面向律师、企业法务与合规人员的一站式法律测算工具集。覆盖**诉讼费用**（受理费、财产保全费与保全担保费（两个独立计算器）、执行费、律师费、公告费、公证费、司法鉴定费、评估费）、**利息与违约金**（LPR 利息、迟延履行加倍利息、违约金司法调整）、**劳动争议**（经济补偿金 N、违法解除 2N、加班费、工伤工亡赔偿）、**时效与期限**（诉讼时效、上诉期、申请执行期，自动处理节假日顺延）、**税务**（印花税、个税、社保用工成本）、**差旅费用**与**法务成本**七大类，共 45 个计算器。

每个计算器均输出**分步计算明细 + 法律依据条文 + 实务提示**，测算项可打包为带项目档案（当事人 / 项目人 / 代理人）的汇报报告，一键导出 Markdown / Excel / Word / HTML / PDF / PNG 长图，直接粘贴进微信、钉钉、飞书。

## 示例提示词（Sample Prompts）

1. 100 万标的的买卖合同纠纷，帮我算一下一审受理费，如果走简易程序能省多少？
2. 申请财产保全 500 万，用保险公司保函，按 0.8‰/年、保 1 年，保全保险费和申请费一共多少钱？
3. 员工 2019 年入职、月薪 1 万 5，月底被违法辞退，赔偿金 2N 能主张多少？
4. 合同约定逾期付款按日万分之五计违约金，本金 300 万，从 2025-01-01 拖到今天，违约金是多少？会不会被调减？
5. 3000 万的工程造价鉴定费和资产评估费大概要准备多少预算？
6. 把经济补偿金、违约金、诉讼成本这三项做成一份汇报报告，导出 Word，项目名「A 客户清收专项」，我方 XX 公司、对方 A 客户，项目人张三、代理人李四。
